Implementation lanes

  1. Client transport: shared typed origin/request policy, hosted fetch adapter, narrow Electron execution, generation invalidation.
  2. Rails perimeter: public route and origin allow-lists, body and rate bounds, trusted proxy policy, redacted errors, readiness.
  3. Connector: outbound HTTPS Rooms access with redirects disabled while preserving durable retry/dedupe semantics.
  4. Alpha ingress: secret-free Cloudflare example and operator runbook; no account mutation or deployment.
  5. Evidence: focused tests and package checks only, secret scan, exact commits, final branch push with no PR.

Hard gates

  • No live infrastructure, credential issuance, real-room writes, provider turns, PR, merge, or deployment.
  • No bearer, invite, bootstrap, device, or provider credential in URLs, logs, persisted source state, or reports.
  • Live acceptance remains UNRUN until separately authorized and human-controlled.
  • Completion target: implemented branches pushed for an authorized alpha gate.
